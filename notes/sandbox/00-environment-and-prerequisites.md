## OpenCue Python Version Requirements

`pycue/pyproject.toml` and `proto/pyproject.toml` declare `requires-python = ">3.7"` **with no upper bound**. However, that does not guarantee bleeding-edge Python releases install seamlessly—practical blockers usually stem from whether compiled binary wheels exist for key dependencies (`grpcio`, `PySide6`). Python 3.12 bundled with Ubuntu 24.04 is a stable target.

## Mandatory Directories (Created within WSL Ubuntu)

```bash
mkdir -p /tmp/rqd/logs /tmp/rqd/shots /tmp/opencue ~/.opencue/sessions
```

Directory roles:

| Path | Purpose |
|---|---|
| `/tmp/rqd/logs` | Frame log output directory; referenced by Cuebot via `CUE_FRAME_LOG_DIR`; also read-only mounted into CueWeb for frame log preview. |
| `/tmp/rqd/shots` | Shot working directory. |
| `/tmp/opencue` | Temporary cache for `pyoutline`. |
| `~/.opencue/sessions` | Store for `outline.yaml` files generated by `pyoutline`; must be accessible by RQD when launching frames. |

**Important Note**: Three of these four paths reside under `/tmp` and are wiped upon system reboot (or WSL shutdown). While acceptable for rapid sandbox validation, production environments must map these to persistent shared storage; see [`01-platform-differences-and-portainer.md`](01-platform-differences-and-portainer.md).
