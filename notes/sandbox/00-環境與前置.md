## OpenCue 對 Python 版本的要求

`pycue/pyproject.toml` 與 `proto/pyproject.toml` 都只寫 `requires-python = ">3.7"`，
**沒有上限**。但這不代表新版 Python 一定能裝 —— 實際卡點通常在相依套件
（grpcio、PySide6）有沒有對應版本的 wheel。Ubuntu 24.04 內建的 3.12 是安全牌。

## 必要目錄（在 WSL Ubuntu 內建立）

```bash
mkdir -p /tmp/rqd/logs /tmp/rqd/shots /tmp/opencue ~/.opencue/sessions
```

用途：

| 路徑 | 用途 |
|---|---|
| `/tmp/rqd/logs` | frame log 輸出，Cuebot 用 `CUE_FRAME_LOG_DIR` 指向這裡；CueWeb 也唯讀掛載它做 frame preview |
| `/tmp/rqd/shots` | shot 工作目錄 |
| `/tmp/opencue` | pyoutline 的暫存 |
| `~/.opencue/sessions` | pyoutline 產生的 `outline.yaml` 存放處，RQD 執行 frame 時要讀得到 |

**注意**：這四個目錄有三個在 `/tmp` 底下，重開機（或 WSL 重啟）就會消失。
sandbox 測試無所謂，但正式環境必須換成持久化路徑 —— 見 `01` 的說明。
